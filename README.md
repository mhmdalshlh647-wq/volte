# 📶 فني VoLTE – يمن موبايل (VoLTE Technician)

تطبيق أندرويد متكامل ومرجع فني أوفلاين شامل لخدمة **VoLTE** وقواعد بيانات أجهزة يمن موبايل، إعدادات APN، أكواد الهاتف السرية (Secret Codes)، ودليل حل المشاكل الشائعة.

---

## 📱 تحميل وتثبيت التطبيق (Install APK)

يمكنك الحصول على ملف التطبيق الجاهز للتثبيت (**APK**) من خلال GitHub مباشرة بأحد الطريقتين:

### الطريقة الأولى: التحميل الآلي من GitHub Actions (Build Artifacts)
1. افتح تبويب **Actions** في أعلى مستودع GitHub هذا.
2. اضغط على أحدث تشغيل لعملية البناء (**Build & Release Android APK**).
3. في أسفل الصفحة تحت قسم **Artifacts**، ستجد ملف **`VoLTE-Technician-App-Debug`**.
4. قم بتحميل الملف وفك الضغط عنه للحصول على ملف `app-debug.apk` وقوم بتثبيته على هاتفك الأندرويد.

---

## 🛠️ بناء التطبيق محلياً (Build Locally)

لبناء ملف الـ APK يدويًا على جهازك:

```bash
# بناء ملف APK النسخة التجريبية
gradle :app:assembleDebug

# سينتج ملف الـ APK في المسار التالي:
# app/build/outputs/apk/debug/app-debug.apk
```

## ✨ ميزات التطبيق

* **📱 قاعدة بيانات شاملة للأجهزة**: تصنيف الأجهزة (دعم تلقائي كامل، دعم حسب الشريحة، تطبيق يمن موبايل، وبرمجة أدوات).
* **🌐 إعدادات APN المعتمدة**: إمكانية نسخ إعدادات `ims` و `ymdata` و `xcap` بضغطة زر واحدة.
* **#️⃣ الأكواد البرمجية والسرّية**: فهرسة كاملة حسب الشركات المصنعة ومعالجات (Samsung, Xiaomi, MTK, Unisoc, Vivo, etc).
* **🛠️ حلول المشاكل الشائعة**: 9 مشاكل تقنية موثّقة مع خطوات حل تفصيلية وتحذيرات هامة من طرق التفعيل الخاطئة (مثل GCF Mode و Shizuku).
* **🔍 أداة مطابقة الهاتف**: قراءة مواصفات نظام الأندرويد ومطابقتها مع القاعدة.
* **🌙 دعم الوضع الداكن والفاتح**: واجهات Material Design 3 سلسة وسريعة ومتوافقة مع اللغة العربية (RTL).
* **🔒 أوفلاين 100%**: لا يتطلب اتصال بالإنترنت ولا يجمع أية بيانات شخصية.
